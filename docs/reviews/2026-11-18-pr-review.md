Findings from building it (already documented in the READMEs and the network plan; good material for the presentation):

- CloudStack VPC ACLs enforce only the **last** CIDR of a multi-CIDR rule, so every rule has exactly one CIDR (`opentofu/educloud/network.tf`).
- A NetBird network **without a policy stays inactive**: its routing peer does not masquerade, and traffic from the LAN behind it is dropped (`ansible/README.md`, role netbird).
- The VPC router's DNS (school resolvers) returned stale IPs for Docker Hub and Quay, so EduCloud VMs use Cloudflare.
- The admin PC: Cisco Secure Client had set a Windows policy that prohibits DNS over HTTPS (`DoHPolicy=1`, rewritten at every boot) and the home network drops DNS answers with private IPs. Fixed by removing Cisco and turning on DoH. Brave works with Rancher; Firefox's live connection (kubectl shell) did not.
